# מד מדף

מעקב אחרי כמה נשאר במוצרי קוסמטיקה באריזות אטומות, לפי שקילה.

## איך זה מחשב

בשקילה הראשונה (מוצר סגור, לפני השימוש הראשון) נגזר משקל התוכן מהנפח המוצהר ומצפיפות אופיינית לסוג המוצר. מכאן כל ירידה במשקל היא כמות שנוצלה. התוצאה מוצגת כטווח, כי הצפיפות משוערת ומותגים ממלאים עד כ‑6% מעל המוצהר.

כשמוצר נגמר ושוקלים את האריזה הריקה, מתקבלת הצפיפות האמיתית. היא נשמרת, וכל מוצר חדש מאותו סוג מחושב לפיה — הטווח מצטמצם מאוד.

התחזית ("נשאר לחודש") מבוססת בהתחלה על הרגלי השימוש שהוזנו, ומרגע שיש שתי שקילות בהפרש של כמה ימים היא עוברת לקצב מדוד אמיתי. אם לא הוזנו הרגלי שימוש, פשוט אין תחזית עד השקילה השנייה — האחוזים עדיין מוצגים.

מוצר שנשקל אבל עוד לא נפתח יושב במלאי: בלי תחזית ובלי התראות, עד שמסמנים שהתחיל השימוש. מאותו יום מתחילה הספירה.

## העלאה

GitHub Pages:

1. להעלות את כל הקבצים לענף `main` בריפו.
2. Settings → Pages → Source: `main`, תיקייה `/ (root)`.
3. לפתוח את הכתובת בכרום בטלפון → תפריט שלוש הנקודות → **הוספה למסך הבית**.

חובה HTTPS (GitHub Pages נותן את זה) כדי שה‑service worker וההתראות יעבדו.

## התראות

עובדות בכרום על אנדרואיד, ורק אחרי שהאפליקציה נוספה למסך הבית. מופעלות מתוך ההגדרות. המערכת מעירה את האפליקציה ברקע בערך פעם ביום ובודקת מה עומד להיגמר — העיתוי המדויק נתון לדפדפן. בכל פתיחה של האפליקציה נעשית אותה בדיקה ממילא, כך ששום דבר לא מתפספס.

## נתונים

הכל נשמר על המכשיר ב‑IndexedDB. שום דבר לא נשלח לשום מקום, ואין שרת. **כדאי לייצא לקובץ מדי פעם** (הגדרות → ייצוא) — ניקוי נתוני דפדפן או החלפת טלפון מוחקים הכל.
